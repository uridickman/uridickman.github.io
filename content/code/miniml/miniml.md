##### Description

MiniML is an implementation of linear and logistic regression, and regression neural networks using only Numpy and standard Python libraries.
This includes stochastic gradient descent algorithms, learning rate scheduling, a small library of activation functions and losses, and working examples with synthetic data.

I plan to expand this code to handle convolutional and graph neural networks to train image classification and possibly generative architectures.
